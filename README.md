# Job Listing Portal – MERN Stack Web Application

A full-stack Job Listing Portal built using the **MERN Stack (MongoDB, Express.js, React.js, and Node.js)** that connects job seekers with employers through a centralized recruitment platform.

The application provides role-based authentication, job management, candidate applications, profile management, and dedicated dashboards to simplify the recruitment process.

## Overview

The Job Listing Portal is designed to provide a seamless hiring experience for both job seekers and employers.

Job seekers can create profiles, upload resumes, explore job opportunities, and apply for relevant positions. Employers can create company profiles, publish job openings, manage listings, and review applications received from candidates.

## Key Features

### Authentication & Authorization
- User registration and login.
- JWT-based authentication.
- Role-based access for Job Seekers and Employers.
- Secure password hashing.

### Job Seeker Features
- Create and manage personal profiles.
- Upload and update resumes and profile pictures.
- Browse available job opportunities.
- Search and filter jobs by keywords, location, and job type.
- Apply for job openings.
- Track submitted applications.

### Employer Features
- Create and manage company profiles.
- Post new job opportunities.
- Edit and delete existing job listings.
- View and manage candidate applications.
- Monitor applicants through the employer dashboard.

### Job Management
- Complete CRUD operations for job postings.
- Detailed job information, including:
  - Job title
  - Description
  - Responsibilities
  - Qualifications
  - Location
  - Salary range
  - Employment type

### User Interface
- Responsive user interface.
- Dedicated dashboards for different user roles.
- Organized navigation and user-friendly layouts.

## Security

- Passwords are stored using secure hashing.
- JWT-based authentication protects authenticated routes.
- Role-based authorization restricts access to relevant features.
- Environment variables are used for sensitive configuration.
- Uploaded files are handled using Multer.
